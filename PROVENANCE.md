# Provenance and Attribution

This file records what is known about the origin of this repository and what should not be inferred from it.

## Source status

The project began from a third-party academic project package that was shared by a classmate. The exact upstream repository, download page, vendor, and license terms are not currently known.

Because the original redistribution rights are unresolved, this repository should be treated as a portfolio and review artifact, not as an open-source project that grants reuse rights.

## What came from the base project

The base package provided the broad project idea: cryptocurrency price prediction with Python machine learning code and a Django-style demonstration app. It also included historical cryptocurrency data and earlier model artifacts or reports.

The original package is not represented here as wholly original work by Aakash Naidu.

## What this repository contributes

This repository presents a revised and documented version focused on reproducible evaluation:

- chronological train/validation/test splits
- next-day forecasting framing
- persistence baseline comparison
- leakage and feature-availability checks
- evaluation metrics and result reporting
- tests and CI checks
- cleaned documentation and setup instructions

## Publication limits

No open-source license is granted at this time. Do not assume that the original project package, bundled datasets, or derived artifacts may be reused outside review of this portfolio repository.

If the upstream source and license are later identified, this file should be updated with exact links, license text, and any required attribution.
